# claude-slim

60秒内减少Claude Code的token开销。

[English](../README.md) | [한국어](./README.ko.md) | [日本語](./README.ja.md)

## 问题

每次启动Claude Code会话时，系统提示词会加载所有已注册的技能描述、记忆文件、工具列表和插件指令。随着安装的技能和插件增多，这些开销会悄然增长。

| 来源 | 开销示例 |
|------|---------|
| 60+已注册技能 | ~3,000 tokens |
| CLAUDE.md（插件指令） | ~5,000 tokens |
| 记忆文件 | ~2,500 tokens |
| Deferred tools列表 | ~1,500 tokens |
| **合计** | **~12,000 tokens/会话** |

在你说"你好"之前，每条消息就已消耗12K tokens。

无论使用社区技能包、团队自定义技能、市场插件还是手动安装的工具，**任何组合**都会出现这个问题。安装越多，负担越重。

## claude-slim的功能

```
/claude-slim
```

查找并消除token浪费的4阶段流水线：

**1. Scan** — 测量所有token开销来源：本地技能、插件技能、CLAUDE.md、记忆文件、MCP服务器。

**2. Analyze** — 自动检测问题：

| 检测项 | 示例 |
|--------|------|
| 断开的符号链接 | 卸载技能包后残留的链接 |
| 重复技能 | 同一技能从多个来源注册 |
| 空模板 | 没有实际内容的占位技能 |
| 超大文件 | 超过10KB的SKILL.md |
| 过期记忆 | 每次会话加载的大型记忆文件 |

**3. Propose** — 展示分为三级的分类报告：
- **Auto** — 可安全移除（断开的链接、空模板）。已预选。
- **Recommended** — 可能未使用（重复项、过期文件）。建议移除。
- **Optional** — 由你决定（超大技能、很少使用的项目）。仅供参考。

接受默认值或选择特定项目。

**4. Report** — Before/After对比 + 预估token节省量。

```
┌────────────────┬──────────┬──────────┬────────────┐
│                │  Before  │  After   │  节省      │
├────────────────┼──────────┼──────────┼────────────┤
│ 本地技能       │    65    │    15    │  -50       │
│ 系统提示词     │   ~80    │   ~48    │  -32       │
│ 记忆文件       │   15KB   │    2KB   │  -13KB     │
│ 预估tokens    │  ~8,500  │  ~4,200  │  ~4,300    │
└────────────────┴──────────┴──────────┴────────────┘
```

## 安装

```bash
claude plugin marketplace add iops-leo/claude-slim
claude plugin install claude-slim
```

## 使用方法

```bash
/claude-slim              # 完整流水线：扫描 → 建议 → 执行 → 报告
/claude-slim scan         # 仅报告，不做更改
/claude-slim restore      # 撤销：恢复之前禁用的项目
```

## 安全性

- **非破坏性。** 不会删除任何东西。禁用的项目移至 `~/.claude/skills.disabled/`。
- **可恢复。** 运行 `/claude-slim restore` 随时恢复。
- **用户可控。** 更改前始终请求确认。你精确选择要禁用的内容。
- **不触碰危险区域。** 绝不修改CLAUDE.md、settings.json或插件配置。

## 不会做的事

- 修改CLAUDE.md（由插件管理 — 编辑会导致故障）
- 禁用插件或MCP服务器（风险太高 — 请自行管理）
- 删除文件（始终移至 `.disabled`）
- 未经批准执行（需要明确确认）

## 工作原理

claude-slim扫描以下位置：

| 位置 | 内容 |
|------|------|
| `~/.claude/skills/` | 用户安装的本地技能 |
| `~/.claude/plugins/cache/` | 已安装的插件技能 |
| `~/.claude/CLAUDE.md` | 插件注入的指令 |
| `~/.claude/projects/*/memory/` | 自动记忆文件 |
| `~/.claude/settings.json` | MCP服务器数量（只读） |

无论使用哪些插件都能工作。没有插件特定逻辑 — 纯粹的文件系统分析。

## 实际效果

此工具诞生于一次真实的清理会话，该环境在数月内从多个来源积累了大量技能：

| 指标 | Before | After |
|------|--------|-------|
| 本地技能 | 65 | 15 |
| 系统提示词技能 | ~80 | ~48 |
| 记忆文件 | 15KB | 2KB |
| **预估token节省** | | **~4,300/会话** |
