# claude-slim

Claude Code 토큰 오버헤드를 60초 만에 줄여줍니다.

[English](../README.md) | [日本語](./README.ja.md) | [中文](./README.zh.md)

## 문제

Claude Code는 세션이 시작될 때마다 등록된 스킬 설명, 메모리 파일, 도구 목록, 플러그인 지침을 시스템 프롬프트에 전부 로드합니다. 스킬과 플러그인을 설치할수록 이 오버헤드는 조용히 늘어납니다.

| 항목 | 예상 오버헤드 |
|------|-------------|
| 60개 이상 등록된 스킬 | ~3,000 토큰 |
| CLAUDE.md (플러그인 지침) | ~5,000 토큰 |
| 메모리 파일 | ~2,500 토큰 |
| Deferred tools 목록 | ~1,500 토큰 |
| **합계** | **~12,000 토큰/세션** |

"안녕"이라고 말하기도 전에 매 메시지마다 12K 토큰이 소모됩니다.

커뮤니티 스킬팩, 팀 커스텀 스킬, 마켓플레이스 플러그인, 직접 설치한 도구 등 **어떤 조합이든** 상관없이 발생합니다. 많이 설치할수록 무거워집니다.

## claude-slim이 하는 일

```
/claude-slim
```

토큰 낭비를 찾아 제거하는 4단계 파이프라인:

**1. Scan** — 모든 토큰 오버헤드 소스 측정: 로컬 스킬, 플러그인 스킬, CLAUDE.md, 메모리 파일, MCP 서버.

**2. Analyze** — 문제 자동 탐지:

| 탐지 항목 | 예시 |
|-----------|------|
| 끊어진 심볼릭 링크 | 스킬팩 제거 후 남은 링크 |
| 중복 스킬 | 여러 소스에서 같은 스킬 등록 |
| 빈 템플릿 | 내용 없는 플레이스홀더 스킬 |
| 대용량 파일 | 10KB 이상 SKILL.md |
| 오래된 메모리 | 매 세션 로드되는 대용량 메모리 파일 |

**3. Propose** — 3단계로 분류된 리포트 제시:
- **Auto** — 안전하게 제거 가능 (끊어진 링크, 빈 템플릿). 자동 선택됨.
- **Recommended** — 미사용 가능성 높음 (중복, 오래된 파일). 권장.
- **Optional** — 사용자 판단 (대용량 스킬, 거의 안 쓰는 항목). 참고용.

기본값 수락 또는 개별 항목 선택 가능.

**4. Report** — Before/After 비교 + 예상 토큰 절감량.

```
┌────────────────┬──────────┬──────────┬────────────┐
│                │  Before  │  After   │  절감      │
├────────────────┼──────────┼──────────┼────────────┤
│ 로컬 스킬      │    65    │    15    │  -50       │
│ 시스템 프롬프트 │   ~80    │   ~48    │  -32       │
│ 메모리 파일     │   15KB   │    2KB   │  -13KB     │
│ 예상 토큰      │  ~8,500  │  ~4,200  │  ~4,300    │
└────────────────┴──────────┴──────────┴────────────┘
```

## 설치

```bash
claude install gh:iops-leo/claude-slim
```

## 사용법

```bash
/claude-slim              # 전체 파이프라인: 스캔 → 제안 → 실행 → 리포트
/claude-slim scan         # 리포트만 (변경 없음)
/claude-slim restore      # 이전에 비활성화한 항목 복구
```

## 안전성

- **비파괴적.** 아무것도 삭제하지 않습니다. 비활성화 항목은 `~/.claude/skills.disabled/`로 이동됩니다.
- **복구 가능.** `/claude-slim restore`로 언제든 복구할 수 있습니다.
- **사용자 제어.** 항상 실행 전 확인을 요청합니다. 정확히 무엇을 비활성화할지 직접 선택합니다.
- **위험 영역 미접촉.** CLAUDE.md, settings.json, 플러그인 설정을 절대 건드리지 않습니다.

## 하지 않는 것

- CLAUDE.md 수정 (플러그인이 관리 — 편집하면 고장남)
- 플러그인/MCP 서버 비활성화 (위험 — 직접 관리하세요)
- 파일 삭제 (항상 `.disabled`로 이동)
- 승인 없이 실행 (명시적 확인 필요)

## 동작 원리

claude-slim은 다음 위치를 스캔합니다:

| 위치 | 내용 |
|------|------|
| `~/.claude/skills/` | 사용자 설치 로컬 스킬 |
| `~/.claude/plugins/cache/` | 설치된 플러그인 스킬 |
| `~/.claude/CLAUDE.md` | 플러그인 주입 지침 |
| `~/.claude/projects/*/memory/` | 자동 메모리 파일 |
| `~/.claude/settings.json` | MCP 서버 수 (읽기 전용) |

어떤 플러그인을 쓰든 상관없이 동작합니다. 플러그인 특화 로직 없이 순수 파일시스템 분석입니다.

## 실제 결과

이 도구는 수개월간 여러 소스에서 스킬이 누적된 환경의 실제 정리 세션에서 탄생했습니다:

| 지표 | Before | After |
|------|--------|-------|
| 로컬 스킬 | 65 | 15 |
| 시스템 프롬프트 스킬 | ~80 | ~48 |
| 메모리 파일 | 15KB | 2KB |
| **예상 토큰 절감** | | **~4,300/세션** |
