# claude-slim

**당신의 Claude Code는 "안녕"이라고 말하기도 전에 토큰을 태우고 있습니다.**

세션이 시작될 때마다 모든 스킬, 메모리 파일, 플러그인 지침이 시스템 프롬프트에 로드됩니다 — 한 번도 안 쓰는 것까지. claude-slim이 그 낭비를 찾아 제거합니다.

[English](../README.md) | [日本語](./README.ja.md) | [中文](./README.zh.md)

### 문제를 시각화하면

```
  세션 시작 시 토큰 예산
  ┌──────────────────────────────────────────────────┐
  │██████████████████████████░░░░░░░░░░░░░░░░░░░░░░░░│ claude-slim 적용 전
  │ 12K 토큰 소모 ↑          실제 작업 ↑             │
  ├──────────────────────────────────────────────────┤
  │██████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░│ claude-slim 적용 후
  │ 5K ↑              작업 공간 확보 ↑               │
  └──────────────────────────────────────────────────┘
```

오버헤드가 숨어있는 곳:

| 항목 | 일반적인 오버헤드 |
|------|:---:|
| 60개 이상 등록된 스킬 | ~3,000 토큰 |
| CLAUDE.md (플러그인 지침) | ~5,000 토큰 |
| 메모리 파일 | ~2,500 토큰 |
| Deferred tools 목록 | ~1,500 토큰 |
| **합계** | **~12,000 토큰** |

## 명령어 하나. 5단계 파이프라인.

```
/claude-slim
```

```
 ┌────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌────────┐
 │  Scan  │ → │ Analyze │ → │ Propose │ → │ Execute │ → │ Report │
 │        │   │         │   │         │   │         │   │        │
 │ 모든   │   │ 끊어진  │   │ 사용자  │   │.disabled│   │before  │
 │ 소스   │   │ 중복    │   │ 가      │   │  로     │   │  vs    │
 │ 측정   │   │ 비대    │   │ 선택    │   │  이동   │   │ after  │
 └────────┘   └─────────┘   └─────────┘   └─────────┘   └────────┘
```

**Scan** — 모든 것을 측정: 로컬 스킬, 플러그인 스킬, CLAUDE.md, 메모리 파일, MCP 서버.

**Analyze** — 낭비를 자동으로 찾아냄:

| | 탐지 대상 |
|---|---|
| 끊어진 심볼릭 링크 | 스킬팩 제거 후 남은 죽은 링크 |
| 중복 스킬 | 여러 소스에서 같은 스킬 등록 |
| 빈 템플릿 | 내용 없는 플레이스홀더 스킬 |
| 대용량 파일 | 10KB 이상 SKILL.md |
| 오래된 메모리 | 매 세션 로드되는 대용량 메모리 파일 |

**Propose** — 3단계로 분류, 당신이 결정:

| 단계 | 동작 | 예시 |
|------|------|------|
| **Auto** | 자동 선택 | 끊어진 링크, 빈 템플릿 |
| **Recommended** | 권장 | 중복, 오래된 메모리 |
| **Optional** | 사용자 판단 | 아직 쓸 수 있는 대용량 스킬 |

**Execute** — 선택한 항목을 `~/.claude/skills.disabled/`로 이동. 삭제하지 않음.

**Report** — 정확히 뭐가 바뀌었는지 보여줌:

```
┌────────────────┬──────────┬──────────┬────────────┐
│                │  Before  │  After   │  절감      │
├────────────────┼──────────┼──────────┼────────────┤
│ 로컬 스킬      │    65    │    15    │  -50       │
│ 시스템 프롬프트 │   ~80    │   ~48    │  -32       │
│ 메모리 파일     │   15KB   │    2KB   │  -13KB     │
│ 예상 토큰      │  ~8,500  │  ~4,200  │  ~4,300    │
└────────────────┴──────────┴──────────┴────────────┘
```

## 설치

```bash
claude plugin marketplace add iops-leo/claude-slim
claude plugin install claude-slim
```

## 사용법

```bash
/claude-slim              # 전체 파이프라인
/claude-slim scan         # 리포트만 (변경 없음)
/claude-slim restore      # 전부 복구
```

---

## 안전 최우선

| | |
|---|---|
| **비파괴적** | 아무것도 삭제하지 않음. 비활성화 항목은 `~/.claude/skills.disabled/`로 이동 |
| **복구 가능** | `/claude-slim restore`로 언제든 복구 |
| **사용자 제어** | 실행 전 항상 확인 요청 |
| **위험 영역 미접촉** | CLAUDE.md, settings.json, 플러그인 설정 절대 건드리지 않음 |

## 동작 원리

claude-slim은 아래 위치를 스캔합니다. 플러그인 특화 로직 없이 순수 파일시스템 분석.

```
~/.claude/
├── skills/                  ← 사용자 설치 스킬
├── plugins/cache/           ← 플러그인 스킬
├── CLAUDE.md                ← 플러그인 지침 (읽기 전용)
├── projects/*/memory/       ← 자동 메모리 파일
└── settings.json            ← MCP 서버 수 (읽기 전용)
```

어떤 플러그인 조합이든 동작합니다: OMC, gstack, 커스텀 스킬, 마켓플레이스 플러그인, 또는 아무것도 없어도.
