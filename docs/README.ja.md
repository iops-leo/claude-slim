# claude-slim

**あなたのClaude Codeは「こんにちは」と言う前にトークンを燃やしています。**

セッション開始のたびに、すべてのスキル、メモリファイル、プラグイン指示がシステムプロンプトに読み込まれます — 一度も使わないものまで。claude-slimがその無駄を見つけて除去します。

## コマンド1つ。5ステップ。

```
/claude-slim
```

```
 ┌────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌────────┐
 │  Scan  │ → │ Analyze │ → │ Propose │ → │ Execute │ → │ Report │
 │        │   │         │   │         │   │         │   │        │
 │すべて  │   │ 壊れた  │   │ユーザー │   │.disabled│   │before  │
 │  の    │   │ 重複    │   │  が     │   │  へ     │   │  vs    │
 │ 測定   │   │ 肥大化  │   │ 選択    │   │  移動   │   │ after  │
 └────────┘   └─────────┘   └─────────┘   └─────────┘   └────────┘
```

**Scan** — すべてを測定：ローカルスキル、プラグインスキル、CLAUDE.md、メモリファイル、MCPサーバー。

**Analyze** — 無駄を自動検出：

| | 検出対象 |
|---|---|
| 壊れたシンボリックリンク | スキルパック削除後の残骸 |
| 重複スキル | 複数ソースから同一スキル登録 |
| 空テンプレート | コンテンツのないプレースホルダー |
| 大容量ファイル | 10KB以上のSKILL.md |
| 古いメモリ | 毎セッション読み込まれる大容量メモリ |

**Propose** — 3段階に分類、あなたが決定：

| 段階 | アクション | 例 |
|------|-----------|---|
| **Auto** | 事前選択 | 壊れたリンク、空テンプレート |
| **Recommended** | 推奨 | 重複、古いメモリ |
| **Optional** | ユーザー判断 | まだ使うかもしれない大容量スキル |

**Execute** — 選択した項目を `~/.claude/skills.disabled/` に移動。削除はしません。

**Report** — 何が変わったか正確に表示：

```
┌────────────────┬──────────┬──────────┬────────────┐
│                │  Before  │  After   │  節約      │
├────────────────┼──────────┼──────────┼────────────┤
│ ローカルスキル  │    65    │    15    │  -50       │
│ システムプロンプト│   ~80   │   ~48    │  -32       │
│ メモリファイル   │   15KB   │    2KB   │  -13KB     │
│ 推定トークン    │  ~8,500  │  ~4,200  │  ~4,300    │
└────────────────┴──────────┴──────────┴────────────┘
```

## インストール

```bash
claude plugin marketplace add iops-leo/claude-slim
claude plugin install claude-slim
```

## 使い方

```bash
/claude-slim              # フルパイプライン
/claude-slim scan         # レポートのみ（変更なし）
/claude-slim restore      # すべて復元
```

## 安全第一

| | |
|---|---|
| **非破壊的** | 何も削除しない。無効化項目は `~/.claude/skills.disabled/` に移動 |
| **復元可能** | `/claude-slim restore` でいつでも復元 |
| **ユーザー制御** | 変更前に必ず確認 |
| **危険領域に非接触** | CLAUDE.md、settings.json、プラグイン設定には触れない |

## 動作原理

claude-slimは以下をスキャンします。プラグイン固有ロジックなし — 純粋なファイルシステム分析。

```
~/.claude/
├── skills/                  ← ユーザーインストールスキル
├── plugins/cache/           ← プラグインスキル
├── CLAUDE.md                ← プラグイン指示（読み取り専用）
├── projects/*/memory/       ← 自動メモリファイル
└── settings.json            ← MCPサーバー数（読み取り専用）
```

どのプラグインの組み合わせでも動作：OMC、gstack、カスタムスキル、マーケットプレイスプラグイン、または何もなくても。

## v2.3 の新機能

- **Detector レジストリへのリファクタ (v2.3.0)** — 588 行の単一モジュールだったスキャナを `src/scanner/` 配下の小さな Detector 群へ分割。新しいヒューリスティックの追加が関数 1 つの追記で済むようになりました（CONTRIBUTING.md 参照）。公開 API は変更なし。
- **パス封じ込めガード (v2.2.3)** — すべての破壊的操作が `~/.claude/` 外を指す対象パスを拒否。`runCommand` はシェルを経由せず実行。`temp_cache` のクリーンアップは symlink-safe。
- **レポート符号バグ修正 (v2.2.3)** — 2.2.x 初期に分解テーブルの Saved カラムの符号が反転していた問題を修正。各行で正しい節約量を表示。
- **テスト 85 件（以前は 73 件）** — パス封じ込め、restore ガード、分解テーブル符号、restore-selection の重複排除、トークンキャッシュの atomic flush、カスタム Detector 注入のテストを追加。

## v2.2 の新機能

- **`stale_project` のアトミックな clean/restore** — ファイル単位のループではなく、ディレクトリ全体を 1 回の `rename()` で移動。途中で中断しても、ファイルが元とバックアップに分散する「部分失敗」状態は発生しません。
- **衝突時の明確なエラー** — すでにバックアップが存在するプロジェクトの clean、または既存ディレクトリ上への restore は、OS の難解なエラーではなく、対処法を示すメッセージで失敗します。
- **マニフェスト v2 スキーマ** — 現在無効化されているエントリだけを含む単一 JSON ファイル（`manifest.json`）。restore でエントリ自体を削除するため、clean/restore サイクルを繰り返してもサイズが無限に増加しません。
- **v1 からの自動マイグレーション** — 既存のレガシーマニフェスト（`.claude-slim-manifest.jsonl`）は初回読み取り時に v2 へ自動変換。原本は `.jsonl.bak` として保存されます。
- **クラッシュ安全な書き込み** — tmp ファイルに書き込んでから atomic rename するパターン。停電や SIGKILL でもマニフェストが壊れません。
- **テストカバレッジの拡充** — 66 テスト（以前は 35）。イシュータイプごとの round-trip テスト：`broken_symlink`、`template`、`duplicate`、`skill_dup`、`oversized_skill`、`temp_cache`、`stale_project`。マイグレーションと bounded-growth サイクルテストも追加。
