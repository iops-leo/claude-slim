# claude-slim

Claude Codeのトークンオーバーヘッドを60秒で削減します。

[English](../README.md) | [한국어](./README.ko.md) | [中文](./README.zh.md)

## 問題

Claude Codeはセッション開始時に、登録されたすべてのスキル説明、メモリファイル、ツールリスト、プラグイン指示をシステムプロンプトに読み込みます。スキルやプラグインを追加するほど、このオーバーヘッドは静かに増大します。

| ソース | オーバーヘッド例 |
|--------|---------------|
| 60以上の登録スキル | 〜3,000トークン |
| CLAUDE.md（プラグイン指示） | 〜5,000トークン |
| メモリファイル | 〜2,500トークン |
| Deferred toolsリスト | 〜1,500トークン |
| **合計** | **〜12,000トークン/セッション** |

「こんにちは」と言う前に、毎メッセージ12Kトークンが消費されます。

コミュニティスキルパック、チームカスタムスキル、マーケットプレイスプラグイン、手動インストールツールなど、**どの組み合わせでも**発生します。

## claude-slimの機能

```
/claude-slim
```

トークンの無駄を検出・除去する4フェーズパイプライン：

**1. Scan** — すべてのトークンオーバーヘッドソースを測定：ローカルスキル、プラグインスキル、CLAUDE.md、メモリファイル、MCPサーバー。

**2. Analyze** — 問題を自動検出：

| 検出項目 | 例 |
|---------|---|
| 壊れたシンボリックリンク | スキルパック削除後に残ったリンク |
| 重複スキル | 複数ソースから同じスキルが登録 |
| 空テンプレート | コンテンツのないプレースホルダースキル |
| 大容量ファイル | 10KB以上のSKILL.md |
| 古いメモリ | 毎セッション読み込まれる大容量メモリファイル |

**3. Propose** — 3段階に分類されたレポートを提示：
- **Auto** — 安全に削除可能（壊れたリンク、空テンプレート）。事前選択済み。
- **Recommended** — 未使用の可能性が高い（重複、古いファイル）。推奨。
- **Optional** — ユーザー判断（大容量スキル、使用頻度の低い項目）。参考情報。

デフォルトの承認、または個別項目の選択が可能。

**4. Report** — Before/After比較 + 推定トークン節約量。

```
┌────────────────┬──────────┬──────────┬────────────┐
│                │  Before  │  After   │  節約      │
├────────────────┼──────────┼──────────┼────────────┤
│ ローカルスキル  │    65    │    15    │  -50       │
│ システムプロンプト│   ~80   │   ~48    │  -32       │
│ メモリファイル   │   15KB   │    2KB   │  -13KB     │
│ 推定トークン    │  ~8,500  │  ~4,200  │  ~4,300    │
└────────────────┴──────────┴──────────┴────────────┘
```

## インストール

```bash
claude plugin marketplace add iops-leo/claude-slim
claude plugin install claude-slim
```

## 使い方

```bash
/claude-slim              # フルパイプライン：スキャン → 提案 → 実行 → レポート
/claude-slim scan         # レポートのみ（変更なし）
/claude-slim restore      # 以前に無効化した項目を復元
```

## 安全性

- **非破壊的。** 何も削除しません。無効化された項目は `~/.claude/skills.disabled/` に移動されます。
- **復元可能。** `/claude-slim restore` でいつでも復元できます。
- **ユーザー制御。** 変更前に必ず確認を求めます。何を無効化するか正確に選択できます。
- **危険領域に非接触。** CLAUDE.md、settings.json、プラグイン設定には触れません。

## しないこと

- CLAUDE.mdの変更（プラグインが管理 — 編集すると壊れます）
- プラグイン・MCPサーバーの無効化（リスクが高い — ご自身で管理してください）
- ファイルの削除（常に `.disabled` に移動）
- 承認なしの実行（明示的な確認が必要）

## 動作原理

claude-slimは以下の場所をスキャンします：

| 場所 | 内容 |
|------|------|
| `~/.claude/skills/` | ユーザーインストールのローカルスキル |
| `~/.claude/plugins/cache/` | インストール済みプラグインスキル |
| `~/.claude/CLAUDE.md` | プラグイン注入指示 |
| `~/.claude/projects/*/memory/` | 自動メモリファイル |
| `~/.claude/settings.json` | MCPサーバー数（読み取り専用） |

どのプラグインを使っていても動作します。プラグイン固有のロジックなし — 純粋なファイルシステム分析です。

## 実績

このツールは、数ヶ月間に複数のソースからスキルが蓄積した環境での実際のクリーンアップセッションから生まれました：

| 指標 | Before | After |
|------|--------|-------|
| ローカルスキル | 65 | 15 |
| システムプロンプトスキル | 〜80 | 〜48 |
| メモリファイル | 15KB | 2KB |
| **推定トークン節約** | | **〜4,300/セッション** |
